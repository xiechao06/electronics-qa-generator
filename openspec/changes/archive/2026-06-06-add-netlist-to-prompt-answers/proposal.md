## Why

The answer files generated by `--prompts` currently include questions, answers,
values, units, and tolerances — but not the SPICE netlist. When verifying answers
from an external agent, the user benefits from having the netlist alongside
answers for full context, without needing to cross-reference the JSONL.

## What Changes

- In the answer markdown files emitted by `_generate_prompt_files`, append the
  SPICE netlist for the corresponding schematic after the numbered answers.

## Capabilities

### Modified Capabilities
- `agent-prompt-generation`: Answer files now include a `## Netlist` section
  with the SPICE netlist block after the numbered answers.

## Impact

- `scripts/batch_generate.py`: add a few lines in `_generate_prompt_files` to
  write the netlist into each answer file.
- No new dependencies, no pipeline changes.
